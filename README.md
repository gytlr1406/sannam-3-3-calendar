# 3-3 수시 면접·실기 일정 달력

산남고등학교 3학년 3반 학생들이 자기 면접·실기 일정을 확인하는 달력 페이지입니다.
구글폼 응답 시트를 직접 읽어 오므로, 시트만 고치면 페이지는 자동으로 최신 상태가 됩니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 달력 페이지 (수정할 일 거의 없음) |
| `config.js` | **구글 시트 CSV 주소** 등 설정 (여기만 고치면 됨) |
| `logo.png` | 학교 로고 |

## 구글 시트 연결 방법

1. 구글폼 응답이 모이는 스프레드시트를 엽니다.
2. **파일 → 공유 → 웹에 게시** 를 누릅니다.
3. 왼쪽에서 응답 시트 탭을, 오른쪽에서 **쉼표로 구분된 값(.csv)** 을 고르고 **게시**를 누릅니다.
4. 나오는 주소를 복사해 `config.js`의 `csvUrl` 따옴표 안에 붙여 넣고 저장(커밋)합니다.

## 구글폼 질문 이름 (자동 인식되는 이름)

- 학생 이름: 질문 제목에 **이름** 또는 **성명** 포함
- 대학: **대학** / **학교** / **전형** 포함 (예: `1. 대학명(전형)`)
- 면접일: **면접일** / **실기일** / **일자** / **날짜** 포함 (예: `1. 면접일`)
- 종료일(선택): **종료** 포함 (예: `1. 면접 종료일(기간인 경우)`)
- 학생이 여러 대학을 적게 하려면 `1. 대학명 / 1. 면접일`, `2. 대학명 / 2. 면접일` 처럼 번호를 붙여 반복합니다.

날짜는 `2026-10-15`, `2026. 10. 15`, `10/15`, `10/15~10/16` 형식을 모두 읽습니다.

## 일정 수정·삭제·추가

응답 시트에서 직접 고치면 됩니다. 행을 지우면 달력에서도 사라지고, 새 행을 추가하면 나타납니다.
페이지는 10분마다, 그리고 화면을 다시 볼 때마다 자동으로 다시 불러옵니다. 즉시 반영하려면 **새로고침** 버튼을 누르세요.
